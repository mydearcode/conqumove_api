Required client behavior:
- Use Bearer access token for authenticated HTTP requests
- On 401, call /api/v1/auth/refresh and retry the failed request
- Reconnect Action Cable with the new access token after refresh
- Use stable idempotency_key values for movement batch retries
- Send timestamps as ISO8601 UTC strings
